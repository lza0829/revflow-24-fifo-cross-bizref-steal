# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

## 按业务单 FIFO 占用

冲正可以只带业务单号（`biz_ref`）而不带原正向流水键（`target_entry_key`）：

- **匹配**：只允许占用**同账户、同 `biz_ref`、仍有剩余敞口**的正向；按入账时间（同日按流水 id）升序 FIFO，直到冲正额度满足或正向耗尽。显式 `target_entry_key` 不构成插队权：它必须就是最早未闭口正向，否则整笔失败闭。
- **失败闭**：跨业务单、跨账户、跳号占用一律失败闭——不落 `match_allocations`、不动账户余额，冲正标记「已隔离」并落隔离项与占用证明（带失败原因：`跨业务单占用` / `冲正账户与原单不一致` / `FIFO 乱序占用` / `冲正无原单` / `冲正超额`）。
- **占用计划（本仓选定路径）**：先生成有序占用计划（纯函数 `plan_bizref_fifo`，内存中按 `(booked_at, id)` 排序逐步占用），再一次性落占用、证明、隔离、状态与余额；**计划外禁止落账**。落库侧选定**独立占用表** `match_allocations`（不新增冲正/归并运行快照列）。已有物化占用直接复用，绝不重算挑单。
- **占用证明**：独立表 `allocation_proofs`（归并运行 id、`biz_ref`、有序正向键、FIFO 序、占用分、失败原因、结论），与占用、隔离、余额同一事务写入；只读接口 `GET /api/allocation-proofs?settle_run_id=`，归并台、冲正流水与净额互证均直接展示该证明，禁止旁路计数。
- **部分冲正**：额度无法被 FIFO 完全消化时，已占用部分照常归并（状态「部分归并」），未消化余分进 `quarantine_items`，原因「FIFO 不足」，并记录已占用部分与引用明细；不把整笔标记成功。
- **失败闭**：匹配、占用落库、证明写入、隔离写入、余额写回与归并运行记录在同一事务内，任一步异常整体回滚。
- **同源**：账户余额 = 正向合计 − 占用合计；互证报告逐笔列出冲正 → 正向键与分摊，并校验「报告占用 = 占用表」「占用证明 = 占用表」「占用证明同单同户」「占用严格 FIFO」「敞口 = 正向 − 占用」「余额 = 正向 − 占用」「部分冲正隔离闭环」。

专用夹具：`fixtures/seed_fifo_bizref.json`（只含 `biz_ref` 的冲正，用 `SEED_FILE` 环境变量切换）。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。
